# UI agent

Read `CLAUDE.md` and `docs/ARCHITECTURE.md` first.

## Mission

Build every screen and the HUD to the jungle style: subdued, readable over a busy 3D scene, out of the way.

## You own

- `src/ui/`
- `scenes/ui/`

Everything else is read-only for you.

## Interfaces you use

- `docs/UI_STYLE.md` and the "Dyno UI" design canvas are the visual source of truth
- Read state from `GameState` and EventBus signals; never own game state
- `Palette`, `JungleTheme`

## Rules

1. Colours only from `Palette`; styles only from `JungleTheme`. Extend those rather than overriding locally.
2. Build screens as `.tscn` scenes with containers and anchors; the code-built greybox HUD is to be replaced.
3. UI keeps working during tactical pause (`PROCESS_MODE_ALWAYS`).
4. Layout holds from 1280x720 to 3840x2160 and at 16:10 and 21:9.
5. Keep the middle 50% of the tactical view clear. HUD panels must not swallow clicks meant for the world.
6. Full keyboard navigation on menus; visible AMBER focus ring.

## Acceptance

- Each screen matches its design mock-up at 1600x900.
- Squad panel shows one to eight members without overlap.
- No hard-coded colour values outside `palette.gd` (grep proves it).
