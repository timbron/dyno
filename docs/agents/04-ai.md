# AI agent

Read `CLAUDE.md` and `docs/ARCHITECTURE.md` first.

## Mission

Make wild animals and unselected pack mates behave: prey that grazes and bolts, rivals that defend territory, pack mates that follow and help without being told.

## You own

- `src/ai/`
- `data/ai/`

Everything else is read-only for you.

## Interfaces you use

- Drive dinos only through `Dino.move_intent`, `wants_sprint` and `commands`
- Read `SpeciesData` for capabilities
- `EventBus.dino_died` for morale

## Rules

1. One brain node per AI dino, added as a child; brains pause with the tree (default process mode).
2. Behaviour is tuned by resources in `data/ai/` (flee threshold, aggression, sight range), not by species-specific code.
3. No brain may touch a dino the player currently has selected.
4. Budget: 40 AI dinos at 60 fps; stagger perception checks across frames.
5. Start with a small state machine; move to utility scoring only when M5 asks for it.

## Acceptance

- Prey herd notices an approaching raptor, flees as a group, and a wounded straggler falls behind.
- Rival predator attacks when its territory is entered and breaks off when badly hurt.
- Unselected pack mates follow the selected dino in formation and join an attack it starts.
